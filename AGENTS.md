# Course authoring rules

User instruction, 2026-10-03: all new or revised practices and homework must use established real datasets, not synthetic data. State the source, observation unit, feature availability, target and split limitations. Do not invent latent objects or groups. Random seeds may control splitting, shuffling and model initialisation. Prefer reproducible Colab CPU examples for introductory lessons.

Практики и ДЗ — на известных реальных датасетах; указывайте источник и смысл данных. Материалы двуязычные (RU/EN). Лекции, слайды и видео хранятся в Google Drive; здесь — практика и ДЗ.

## Формат практик «Введение в ПИ» / Practice format

Указание преподавателя от 2026-10-26: каждая новая или перерабатываемая практика содержит ровно четыре задания на написание кода с автоматическими проверками. Чередовать четыре блока: материал → пример кода → подробное задание → ячейка решения студента → проверка. Полные инструкции на русском и английском. Не собирать всю теорию и весь готовый эксперимент перед заданиями. Отдельный преподавательский ноутбук содержит решения, выполненные проверки и содержательные RU/EN-комментарии каждой непустой строки кода; хранить только в закрытой папке Google Drive.

Each new or revised practice has exactly four coding exercises with executable checks. Interleave explanation, worked example, detailed task, student solution cell, and check in each block. Provide full RU/EN instructions and a separate, executed instructor solution with meaningful RU/EN comments on every nonempty code line, stored only in private Google Drive.
